# KT7 — Практикум по алгоритмам

Шесть решений на Java для задач о кратчайших путях и взвешенных графах.

## Задачи

1. **Task1** — кратчайшие пути из одной вершины при неотрицательных весах (алгоритм Дейкстры).
2. **Task2** — кратчайшие пути при отрицательных весах без достижимых отрицательных циклов (Беллман — Форд).
3. **Task3** — ближайший пункт помощи с разрешением равенств по меньшему номеру (мультистартовая Дейкстра).
4. **Task4** — кратчайший путь с купоном, который можно применить не более одного раза (Дейкстра по двум состояниям).
5. **Task5** — недостижимые вершины, конечные расстояния и вершины, достижимые из отрицательных циклов (Беллман — Форд).
6. **Task6** — минимальная стоимость маршрута не более чем из K рёбер и количество таких маршрутов (динамическое программирование по длине).

## Компиляция и запуск

Из корня проекта:

```bash
javac src/Task1.java
java -cp src Task1
```

Для остальных задач замените `Task1` на `Task2`, `Task3`, `Task4`, `Task5` или `Task6`.

## Сложность

- Task1: O((n + m) log n).
- Task2: O(nm).
- Task3: O((n + m) log n).
- Task4: O((n + m) log n).
- Task5: O(nm).
- Task6: O(Km + Kn).
